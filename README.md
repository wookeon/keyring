# Keyring

Mac과 iPhone에서 쓰는 계정 관리 앱입니다. 웹 체험의 계정은 페이지 메모리에만 존재하는 예시이며 실제 로그인·동기화는 하지 않습니다.

- Mac 배포 정보와 최소 OS는 공개 appcast.xml에서 읽습니다.
- iPhone은 내부 TestFlight 안내만 제공합니다. 공개 참여 링크는 현재 없습니다.
- 로컬 미리보기: python3 -m http.server 8765

- 개인정보 처리방침: https://wookeon.github.io/keyring/privacy
