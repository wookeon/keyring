Keyring for Mac

메뉴 막대에서 쓰는 계정 관리 앱입니다. Safari, Chrome, Comet 의 로그인 칸에 아이디·비밀번호·OTP 를 바로 채웁니다.

Mac 용 다운로드

macOS 26 이상 · Apple 공증 완료

기능

브라우저에서 바로 입력

Safari, Chrome, Comet 확장 프로그램이 로그인 칸 아래에 그 사이트의 계정을 보여 줍니다.

로그인하면 저장 제안

새 계정으로 로그인하면 Keyring 에 저장할지 묻고, 비밀번호가 바뀌면 업데이트를 제안합니다.

OTP 코드

2단계 인증 QR 을 등록해 두면 인증 코드도 함께 채웁니다. 메일로 코드가 오는 사이트는 메일함을 열어 줍니다.

Mac 암호 자동 완성

앱 로그인 화면에서도 macOS 자동 완성으로 Keyring 의 계정을 고를 수 있습니다.

iCloud 동기화

같은 Apple 계정으로 로그인한 Mac 끼리 계정을 자동으로 맞춥니다.

쉽게 옮겨 오기

KeePass, Apple 암호, Chrome, Google Authenticator 에서 계정을 가져오고, KeePass 로 열리는 암호화 백업으로 내보냅니다.

안전하게 보관합니다

별도 서버 없음

계정은 이 Mac 과 내 iCloud 비공개 저장소에만 있습니다. 개발자도 볼 수 없습니다.

필요한 계정만 전달

확장 프로그램은 지금 연 사이트에 맞는 계정만 받습니다.

앱 잠금

Touch ID 나 Mac 암호로 Keyring 을 잠글 수 있습니다.

사용 통계와 오류 보고는 Firebase 로 보내며 계정 정보는 포함되지 않습니다. 자세한 내용은 개인정보 처리방침을 확인하세요.

설치

  1. Keyring.dmg 를 내려받아 엽니다.
  2. Keyring 을 응용 프로그램 폴더로 끌어다 놓습니다.
  3. Keyring 을 실행하면 메뉴 막대에 Keyring 아이콘이 생깁니다.
  4. 첫 화면 안내에 따라 Safari 확장을 켜거나 Chrome·Comet 확장을 설치합니다.

업데이트는 새 DMG 를 받아 같은 방법으로 덮어쓰면 됩니다. 저장된 계정은 그대로 남습니다. 이전 버전은 릴리스 목록에 있습니다.
